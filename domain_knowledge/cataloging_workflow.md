# Cataloging Workflow

## Purpose
Provide a repeatable librarian workflow for classifying and organizing books.

## Step-by-Step Workflow
1. Read the title and, if available, the full text.
2. Identify the story type: fable, moral tale, short story, parable, folk tale, or another broad genre.
3. Identify the primary theme.
4. Assign audience and reading level.
5. Add tone and structure if it helps distinguish similar books.
6. Write a short rationale using evidence from the text.
7. Save the classification next to the book when possible.

## Cataloging Principles
- Use the broadest correct category first.
- Use evidence from the story, not assumptions from the title alone.
- Prefer the same taxonomy for all books in the same collection.
- Keep catalog notes short, structured, and reusable.
- If metadata is missing, say "unknown" instead of inventing details.

## Suggested Metadata Record
- title
- author
- genre
- theme
- audience
- reading_level
- tone
- structure
- rationale
- moral

## Quality Check
Before finalizing a catalog record, ask:
- Does the label match the evidence?
- Would a second run likely choose the same category?
- Is the rationale concise and understandable?
