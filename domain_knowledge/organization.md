# Library Organization Conventions

## Folder and File Rules
- Store source books in `library/`.
- Keep file names short, readable, and stable.
- Prefer title-based names such as `The_Proud_Rose.txt` or `The Proud Rose.txt`.
- Avoid path traversal, absolute paths, and ambiguous duplicates.

## Suggested Organization Fields
- Title
- Author, if known
- Genre
- Theme
- Audience
- Reading level
- Moral or lesson

## Sorting Conventions
- Primary sort: genre.
- Secondary sort: theme.
- Tertiary sort: author or title.
- When two books are similar, keep the same naming and category strategy across the library.

## Metadata Practice
- Save metadata next to the book when possible.
- Keep generated metadata deterministic and concise.
- Use the same category vocabulary across the library.
